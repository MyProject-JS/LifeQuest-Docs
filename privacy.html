⚔️ LifeQuest 개인정보처리방침 Privacy Policy

최종 수정일: 2026년 11월 4일

LifeQuest(이하 "앱" 또는 "서비스")는 사용자의 개인정보를 매우 소중하게 생각하며, 관련 법령 및 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 엄격히 준수합니다. 본 방침은 앱이 사용자의 정보를 어떻게 수집, 사용, 보관 및 보호하는지 투명하게 안내합니다.

1. 수집하는 정보 및 수집 목적

LifeQuest는 사용자의 명시적인 동의하에 최소한의 필수 정보만을 처리합니다.

  • Google 이메일 주소 (userinfo.email): 앱 내에서 Google 계정 연동 상태를 확인하고 표시하기 위해서만 사용됩니다.
  • Google Drive 전용 파일 (drive.file): LifeQuest 앱이 생성한 퀘스트 백업 데이터(LifeQuest_CloudSave.json 및 진행 상황 텍스트 파일)를 사용자의 개인 Google Drive 내 [LifeQuest] 폴더에 안전하게 보관하고 다른 기기와 동기화하기 위해서만 사용됩니다. (주의: 사용자의 다른 구글 드라이브 파일에는 일체 접근하지 않습니다.)
  • Google Calendar 일정 (calendar.events): 사용자가 앱 내에서 퀘스트를 구글 캘린더에 일정으로 등록하거나 가져올 때만 사용됩니다.

2. 개인정보의 공유 및 제3자 제공 금지

LifeQuest는 독립 실행형 개인 생산성 애플리케이션으로 운영됩니다.

  • 수집된 구글 사용자 데이터는 어떠한 제3자, 외부 광고 네트워크, 분석 기업에도 판매, 대여 또는 공유되지 않습니다.
  • 모든 퀘스트 및 백업 데이터는 오직 사용자의 로컬 컴퓨터와 사용자의 개인 Google 클라우드 계정에만 직접 보관됩니다.

🛡️ Google API 서비스 제한적 사용 요건 준수 (Limited Use Disclosure)

LifeQuest's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. 데이터 보관 및 파기

  • 연동 해제: 앱 내 설정 메뉴에서 [구글 계정 연동 해제] 버튼을 클릭하면 즉시 로컬에 저장된 모든 인증 토큰이 안전하게 파기됩니다.
  • 구글 권한 취소: 사용자는 언제든지 Google 계정 권한 관리 센터에서 LifeQuest에 부여된 권한을 즉시 취소할 수 있습니다.
  • 데이터 삭제: Google Drive의 [LifeQuest] 폴더 및 파일은 사용자가 직접 언제든지 영구 삭제할 수 있습니다.

4. 보안 조치

LifeQuest는 업계 표준 OAuth 2.0 공식 루프백 인증 프로토콜(Authorization Code Flow with PKCE)을 사용하며, 모든 통신은 SSL/TLS 암호화 채널(HTTPS)을 통해 구글 공식 서버와 직접 통신합니다.
